# Покерный трекер (данные хранятся на компьютере)

## Как запустить

Дважды щёлкните **«Запустить трекер.bat»**. Откроется чёрное окно, и трекер сам откроется в браузере.
Пока пользуетесь трекером, не закрывайте чёрное окно. Чтобы выйти, просто закройте его.

Нужен Python 3 (python.org). Ничего больше устанавливать не надо.

## Где лежат данные

- `data\poker.db` — все сессии, раздачи и настройки в одном файле.
- `data\backups\` — резервные копии. Создаются сами раз в день при запуске, хранятся последние 14.

Чтобы перенести трекер на другой компьютер, скопируйте всю папку вместе с `data`.
Чтобы откатиться к копии, закройте трекер и замените `data\poker.db` файлом из `data\backups`, переименовав его в `poker.db`.

## Перенос из браузерной версии

1. Откройте `index.html` из этой папки двойным кликом (не через .bat), в том же браузере, где работала старая версия.
2. Если там найдутся старые данные, появится кнопка «Скачать данные из браузера». Нажмите её.
3. Запустите трекер через .bat и выберите «Настройки» → «Загрузить из JSON-копии».

Если старая версия ещё открывается, можно и проще: в ней «Настройки» → «Скачать резервную копию», затем загрузить этот файл здесь.

## Что умеет

То же, что и браузерная версия: сессии и банкролл, импорт истории раздач PokerStars и GGPoker, VPIP, PFR, 3-бет, AF, WTSD, bb/100, графики, позиции, стартовые руки и статистика оппонентов.

### История турниров (вкладка «Турниры»)

- Список всех турниров: дата, рум, название, бай-ин, ре-энтри, игроков, место, выигрыш, профит, ROI, число раздач. Таблицу можно сортировать и фильтровать по периоду, формату, руму, бай-ину и названию.
- Итоги: профит, ROI, ITM, финальные столы, победы, лучший занос, средний финиш, заработок в час.
- Графики: накопительный профит и «где вылетаю» (место в процентах от поля). Разбивка по бай-инам, форматам и румам.
- По клику на турнир открываются подробности: место и процент поля, длительность, график стека по раздачам, крупнейшие раздачи.
- **Сводки турниров** (tournament summary) PokerStars и GGPoker загружаются там же, где и раздачи. Место, выигрыш, число игроков, ре-энтри и призовой фонд подставятся сами. В PokerStars сохранение сводок включается в настройках («Воспроизведение и история»): файлы `TS…txt` лягут в папку истории раздач.
- Если раздачи турнира загружены, а сводки нет, турнир попадёт в список «Турниры из раздач без результата». Там можно вписать место и выигрыш вручную.
- Турниры — это часть общего списка сессий, поэтому они сразу учитываются в банкролле и на вкладке «Обзор».

## Для разработчика

- `server.py` — локальный сервер на стандартной библиотеке Python. Принимает запросы только с этого компьютера (127.0.0.1).
- Переменные окружения: `POKER_TRACKER_DATA` (папка данных), `POKER_TRACKER_PORT` (первый порт, по умолчанию 8765), `POKER_TRACKER_NO_BROWSER=1`.
- `node test-parser.js` — проверка разбора раздач.
